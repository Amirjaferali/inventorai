## 3. The lowercase `undetermined` decision (F4)

Lowercase `undetermined` is deliberately **NOT** a blanket Prohibited Token:
it is legitimate English prose (the hygiene module itself cites
"Responsibility undetermined" as honest inventor-facing wording that must
not be flagged). It is prohibited ONLY as the exact FIELD VALUE of
`criticality_authority` — precise coverage without rejecting valid
inventor-facing English.
