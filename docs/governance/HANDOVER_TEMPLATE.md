# InventorAI — Mandatory Handover Template

A handover is **informative, not authoritative**. No owner decision becomes canonical merely
by appearing in a handover. Where a handover conflicts with committed current authority,
committed current authority governs. Any new handover-only idea must be marked
`NOT CANONICAL — REQUIRES OWNER DECISION` and entered into the Owner Decision Register with
committed owner-decision evidence before implementation.

A receiving agent must be able to continue from the five core inputs alone:
`CLAUDE.md → CURRENT_PROJECT_STATE.md → current anchor → OWNER_DECISION_REGISTER.md → active contract`.
